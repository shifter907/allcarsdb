EPA Name Reconciliation

Each row is one distinct EPA model name, not one car — deciding it applies to every row carrying it. Confirming claims the two names are the same vehicle; it does not claim we hold every year EPA does, since the importer still checks each year separately. Leaving a row undecided keeps its data out, which is the safe default. Suggestions are ranked by name and year overlap only — the top one is sometimes wrong, so check the alternates.
